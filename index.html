Custom build

Baking is a compile — 30–45 minutes on a build machine, cached after the first time — so it cannot happen in this tab. Ask for a client with the mods you want and a build runs for you.

A service for this is webmc-mods/tools/build-service.mjs; it drives the build job and serves the finished client.
