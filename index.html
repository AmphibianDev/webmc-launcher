    About

    A launcher page and a small local service. The page is static files; tools/local-ui.py serves it and drives tools/play-local.py, which installs the client into ~/.webmc/minecraft and starts it with java. The launcher library goes into ~/.webmc/venv, so nothing is added to your own Python.

    No game session runs on a CI service, nothing is streamed to a browser, and no game file or other author's mod is redistributed here. Versions marked Rosetta need the x86_64 JDK; the play path fetches the arm64 one today, and the page says so rather than starting a game that cannot load its own graphics libraries.

    Where the numbers come from. versions.json is Mojang's own catalogue. playable.json is tools/scan-playable.py: each version's own document where one was already parsed, the LWJGL boundary (3.3.0 added natives-macos-arm64) otherwise, and every row says which.
